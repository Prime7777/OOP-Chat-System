# OOP Chat System

A mini chat system developed in Python to demonstrate Object-Oriented Programming (OOP) concepts such as classes, objects, constructors, composition, and methods.

## Features

* User joining a chat room
* User leaving a chat room
* Sending messages
* Viewing chat history
* Managing users in a chat room

## Classes Used

### User

Represents a user participating in the chat room.

**Attributes**

* username

**Methods**

* join_chatroom()
* leave_chatroom()
* send_message()

### Message

Represents a message sent by a user.

**Attributes**

* sender
* content
* timestamp

**Methods**

* show_display()

### ChatRoom

Represents the chat room where users communicate.

**Attributes**

* room_name
* users
* chat_history

**Methods**

* add_user()
* remove_user()
* show_chat_history()

## OOP Concepts Demonstrated

* Classes and Objects
* Constructors (`__init__`)
* Composition
* Instance Attributes
* Methods
* Encapsulation
